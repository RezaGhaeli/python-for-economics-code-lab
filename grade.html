Grade exam reports

Re-grade the students’ reports

Drop the .docx reports your students uploaded. Each report carries the code the student wrote; this page grades that code again with the same checks, so a score edited in Word does not count. Everything runs in this browser: nothing is uploaded anywhere.

Results

Flags: score edited the report’s score differs from the re-grade · over time finished more than 2 minutes after the limit · same code a section’s code (ignoring spaces and comments) is identical to another student’s · other exam the report is from a different exam · time limit the exam ended by itself.

Optional: an access code

To stop students starting early, type a code here, copy the hash into exam.accessCode in js/config.js, publish, and announce the code when the exam begins (it is not case-sensitive).
